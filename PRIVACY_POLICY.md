# Политика конфиденциальности

**Действует с:** 8 июня 2026 г.

## 1. Введение

Настоящая политика описывает, как мобильное приложение **«Список покупок — BuyList»** (далее — «Приложение») обрабатывает данные пользователей в соответствии с требованиями RuStore, Google Play и применимых законов о защите персональных данных.

Разработчик приложения — индивидуальный разработчик. Связаться можно по адресу электронной почты: **dz529770@gmail.com**.

## 2. Сбор данных

Приложение работает преимущественно в автономном режиме. Все списки покупок, настройки интерфейса, архивы и данные дисконтных карт хранятся **исключительно локально** на устройстве пользователя.

**Мы не собираем:**
- Персональные идентификационные данные (ФИО, телефон, адрес).
- Данные банковских карт.
- Контакты из телефонной книги.

**Что используется на устройстве:**
- **Голосовой ввод** — обрабатывается исключительно системными средствами распознавания речи Android (Google/Samsung и др.), без передачи на сторонние серверы.
- **Фотографии дисконтных карт** — сохраняются локально во внутреннем хранилище приложения.
- **Рекламный SDK Яндекса (Yandex Mobile Ads)** — имеет доступ к рекламному идентификатору устройства (ADID) в соответствии со своей политикой конфиденциальности для показа контекстной рекламы.

## 3. Использование данных

Собранные данные используются строго для функционирования приложения:
- Отображение и управление списками покупок.
- Работа локальной базы блюд (подсказки ингредиентов без интернета).
- Ведение архива завершённых покупок.
- Хранение цифровых копий дисконтных карт.

**Экспорт списков:** пользователь может по собственной инициативе экспортировать список покупок в файл и поделиться им через мессенджеры или email. Это действие выполняется только при явном выборе пользователем.

## 4. Передача данных третьим лицам

- Данные списков покупок **не передаются** третьим лицам автоматически.
- Рекламный SDK Яндекса обрабатывает рекламный идентификатор устройства самостоятельно в рамках своей политики.
- Файлы экспорта передаются только тем приложениям и контактам, которые **выбирает пользователь** вручную.

## 5. Хранение и безопасность

- Все данные хранятся в **внутреннем хранилище** приложения Android и недоступны другим приложениям (начиная с Android 11 — scoped storage).
- База блюд работает полностью **без подключения к интернету**.
- Применяются стандартные меры защиты на уровне платформы Android (шифрование хранилища на современных устройствах).
- При удалении приложения все локальные данные удаляются вместе с ним.

## 6. Права пользователя

Пользователь в любой момент может:
- Удалить элементы из списка покупок.
- Очистить текущий список покупок.
- Удалить архивные списки.
- Удалить сохранённые дисконтные карты.
- Изменить язык и стиль оформления интерфейса.
- Отключить показ рекламы (при наличии такой опции в приложении).

## 7. Дети

Приложение предназначено для широкой аудитории, не содержит контент 18+ и **не собирает данные детей** специальным образом. Рекламные материалы фильтруются в соответствии с политиками рекламных сетей.

## 8. Изменения политики

Мы можем обновлять настоящую политику конфиденциальности. Актуальная версия всегда доступна:
- Внутри приложения: *Настройки → Политика конфиденциальности*.
- На странице приложения в RuStore.
